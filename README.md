# ARZEGRBY - منصة التمويل الجماعي الذكية

**ARZEGRBY** هي منصة تفاعلية أولى من نوعها للتمويل الجماعي وتطوير البنية التحتية. نحن نحول فكرة "بناء المدن" إلى مجتمع تفاعلي على أرض الواقع.

## 🎯 رؤيتنا
تجميع المواطنين والمتبرعين والمقاولين في بيئة عمل موثوقة وشفافة لتمويل وتنفيذ مشاريع البنية التحتية الحقيقية.

## 👥 أدوار المستخدمين

### المواطنون والمراسلون
- رصد المشاكل والاحتياجات (أضرار الطرق، البنى التحتية)
- اقتراح مشاريع خدمية جديدة
- تحميل الصور والمستندات
- عرض فوري على خريطة التطبيق

### المتبرعون والمستثمرون
- تصفح المشاريع والمشاكل على الخريطة
- تمويل كلي أو جزئي للمشاريع
- متابعة تأثير التبرعات عبر شريط تقدم مباشر
- رؤية الشفافية الكاملة للأموال

### المقاولون
- تصفح المشاريع المكتملة التمويل
- طلب استلام المشاريع للتنفيذ
- الالتزام بشروط ضمان مالي صارم
- دفع تأمين مالي (حتى 80% من قيمة المشروع)

## ⚙️ المميزات الرئيسية

### 1. نظام التوثيق الجغرافي الذكي
- ربط تلقائي للصور المرفوعة
- عرض دقيق على خريطة تفاعلية
- تسهيل الوصول للمشاريع القريبة

### 2. محرك التمويل الجماعي الشفاف
- حساب دقيق للتبرعات الواردة
- خصم مباشر من التكلفة الإجمالية
- تحديث حي للمبلغ المتبقي

### 3. نظام الضمان المالي الصارم
- دفع تأمين مالي من قبل المقاول (حتى 80%)
- حماية شاملة لأموال المتبرعين
- عقوبات صارمة على الإخلال بالشروط
- منع المشاريع الوهمية والتلاعب

## 🔐 نظام المصادقة والتسجيل

### متطلبات التسجيل
- إنشاء حساب بمفاتيح حقيقية
- تأكيد البريد الإلكتروني عبر رابط التفعيل
- عدم السماح بالدخول قبل تأكيد البريد
- معايير أمان عالية للحسابات

## 🚀 البدء السريع

### المتطلبات
- Node.js 16+
- MongoDB

### التثبيت

```bash
git clone https://github.com/ARZEGRBY/ARZEGRBY.git
cd ARZEGRBY
npm install
```

### التشغيل

```bash
npm run dev
```
